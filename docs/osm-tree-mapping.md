# OSM 수목 기여 안내

광교호수공원 AOI 안의 OpenStreetMap 개별 나무(`natural=tree`)는 2026-09 기준 8그루뿐입니다. 공원 수목 그늘은 대부분 위성 수관 높이(CHM)에 기대고 있습니다. CHM은 과거 영상 기준이고 10 m 안팎의 작은 수관을 놓치기 쉬우므로, 현장에서 확인한 나무를 OSM에 올리면 이 지도와 다른 OSM 사용자 모두에게 도움이 됩니다.

OSM에 올린 자료는 ODbL로 공개됩니다. 이 저장소는 `npm run fetch:osm`으로 그 자료를 그대로 가져옵니다.

## 입력할 태그

| 태그 | 예 | 지도에서의 쓰임 |
| --- | --- | --- |
| `natural=tree` | 점(node) | 개별 나무로 그림자 계산 |
| `height` | `9` | 나무 높이(m). 없으면 8 m로 추정 |
| `diameter_crown` | `6` | 수관 지름(m). 없으면 지름 6 m로 추정 |
| `leaf_cycle` | `deciduous`, `evergreen`, `semi_deciduous` | 계절별 그늘. 위성 추정보다 우선 |
| `leaf_type` | `broadleaved`, `needleleaved` | `leaf_cycle`이 없을 때 계절 판단에 사용 |
| `species` / `genus` | `Zelkova serrata` / `Pinus` | 지도 속성으로 보관 |

숲이나 수림대 폴리곤(`natural=wood`)에도 `leaf_type`, `leaf_cycle`을 붙일 수 있습니다. 가로수 열(`natural=tree_row`)은 현재 파이프라인이 읽지 않으므로 나무마다 점으로 입력해 주세요.

높이와 수관 지름은 대략적인 값이어도 기본값보다 낫습니다. 수관 지름은 수관 아래를 걸어서 잰 걸음 수로, 높이는 경사계 앱이나 주변 건물 층수(층당 약 3 m)와 비교해 어림할 수 있습니다.

## 쓸 수 있는 자료와 쓸 수 없는 자료

사용할 수 있는 것은 다음과 같습니다.

- 직접 현장 조사한 내용과 직접 찍은 사진
- OSM 편집기(iD, JOSM)가 기본으로 제공하는 배경 영상. OSM 편집 허락을 받은 영상입니다.

사용하면 안 되는 것은 다음과 같습니다.

- 카카오맵·네이버 지도, 로드뷰·거리뷰, Google 지도·위성 영상
- 국토지리정보원 항공사진, 산림청 임상도, 수원시 내부 자료 등 OSM 기여 허락이 확인되지 않은 공공 자료

편집 도구로는 iD(웹), JOSM(데스크톱), 또는 현장에서 점을 추가하기 좋은 모바일 편집기(Every Door, Vespucci 등)를 쓸 수 있습니다. 편집 요약(changeset comment)에 출처를 `survey`처럼 남겨 주세요.

## 기여 후 반영

OSM 반영 뒤(보통 수 분 안에 Overpass에 나타남) 다음 순서로 다시 생성합니다.

```bash
npm run fetch:osm -- --force
npm run fetch:canopy
npm run fetch:leaf
```

개별 나무는 위성 수관과 함께 계산됩니다. 같은 곳을 둘 다 덮으면 더 강한 그늘 하나로만 셉니다.
